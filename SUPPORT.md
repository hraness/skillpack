# Support

Use [GitHub issues](https://github.com/hraness/skillpack/issues) for public bug
reports, portability problems, routing collisions, and documentation requests.
Include the release or commit, host and version, exact validation command, and
a minimal reproduction when possible.

Do not post credentials, private repository content, or exploitable security
details in a public issue. Use the repository's private vulnerability-reporting
channel for security reports as described in [SECURITY.md](SECURITY.md).
