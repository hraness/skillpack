# Nietzsche Ladder

The upstream slug intentionally remains `nietzche-ladder` for compatibility.
Run only when explicitly invoked.

1. Camel: carry the inherited duties, facts, disciplines, and strongest case
   for the existing values.
2. Lion: expose the commands hidden inside them, negate what cannot be freely
   affirmed, and name the freedom won.
3. Child: create a new relation, value, or question that is not merely the
   inverse of the old one.

Each stage must answer the prior one. Do not reduce the ladder to obedience,
rebellion, and optimism, or present the framing as historical exegesis.
