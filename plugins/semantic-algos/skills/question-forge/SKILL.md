# Question Forge

Run only when explicitly invoked. Return a better question, not its answer.

1. State the surface question faithfully.
2. Diagnose smuggled answers, false binaries, wrong abstraction level,
   ambiguous terms, and self-protective framing.
3. Identify what an honest answer would have to decide, risk, or make visible.
4. Generate candidate transformations at the causal, definitional, and
   responsibility levels.
5. Select the one question that changes the inquiry most without presupposing
   its answer.

Return the forged question and a brief account of what changed. Stop before
answering it.
