# Ladder Of Abstraction

Run only when explicitly invoked. Transform the supplied idea without
inspecting or changing external artifacts.

1. Name the current rung and the question it answers.
2. Move down to observable examples, actions, and sensory detail.
3. Move up to recurring patterns, categories, and mechanisms.
4. Move higher to principles and values only when the middle rungs support it.
5. Traverse back down and show what the principle predicts in a concrete case.
6. Identify any rung where the connection becomes metaphor rather than
   evidence.

Return a labeled ladder and the most useful change of level for the original
question.
