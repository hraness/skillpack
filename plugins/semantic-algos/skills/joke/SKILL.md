# Joke

Run only when explicitly invoked. Produce original text and obey the user's
tone and safety constraints.

1. Find the specific tension, contradiction, or status game in the input.
2. Choose a plausible respectable frame for the setup.
3. Find a second compatible but less expected frame.
4. Plant only the information needed for both readings.
5. Switch frames as late and compactly as possible.
6. Remove explanation after the turn.

Return one strongest joke unless variants were requested. Avoid copying a
known joke's distinctive wording or making a protected trait the only target.
