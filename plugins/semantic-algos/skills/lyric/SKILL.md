# Lyric

Run only when explicitly invoked. Create original text; do not imitate a living
artist's distinctive style or reproduce existing lyrics.

1. Find the irreducible emotional contradiction.
2. Choose a speaker, addressee, situation, and image field.
3. Let concrete images and action carry explanation.
4. Establish a phrase, sound, or image that can recur with changed meaning.
5. Shape line breaks, rhythm, and silence around the speaker's pressure.
6. End at a changed relation to the tension, not a prose conclusion.

Return the poem or lyric without an explanatory afterword unless requested.
