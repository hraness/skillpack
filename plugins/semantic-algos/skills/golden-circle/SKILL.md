# Golden Circle

Run only when explicitly invoked. Clarify the supplied idea; do not implement
or publish it.

1. State `Why`: the purpose, belief, or change sought beyond the artifact.
2. State `How`: the distinctive principles and mechanisms that express it.
3. State `What`: the concrete offering, action, or output.
4. Test directionality: does the What actually instantiate the How, and does
   the How plausibly serve the Why?
5. Identify gaps, borrowed slogans, or circular purpose statements.
6. Return a corrected circle and one sentence that moves from Why to What
   without hiding the mechanism.

Do not invent a noble purpose for a merely instrumental request.
